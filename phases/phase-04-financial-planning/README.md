# Phase 4 — Financial Planning

Status: **future**. This is deliberately separate from the stock portfolio MVP.

## Intended outcome

A broader financial picture covering income, recurring expenses, emergency savings, debt,
employer retirement plans, IRAs, taxable investing, and goal-based allocation.

## Entry gates

- Prove the portfolio product has durable user value.
- Select compliant bank/payroll connection providers and complete security review.
- Define the boundary between education, automated planning, and regulated advice.
- Obtain professional U.S. legal and compliance review before personalized paid guidance.
