# Phase 2 — Web Application

Status: **planned**. Work starts only after Phase 1 proves that users repeatedly open and value
the Telegram brief.

## Intended outcome

A responsive, authenticated portfolio application with manual/CSV portfolio import, a holdings
dashboard, investment-policy settings, evidence-backed decision cards, and a replayable decision
history.

## Entry gates

- Complete a one-market-week Phase 1 pilot with invited users.
- Record brief open/usefulness feedback and the alerts users acted on or ignored.
- Choose a licensed production market-data provider.
- Approve the threat model, tenant isolation design, and canonical portfolio schema.

## Exclusions

No live order placement, options, margin, automated tax advice, or ungrounded LLM calculations.
The implementation brief is in [`planning/CODING_AGENT_BRIEF.md`](../../planning/CODING_AGENT_BRIEF.md).
