# Phase 3 — Connected Portfolios

Status: **planned**. This phase adds approved, read-only connections after the core analytics and
evidence model are reliable.

## Intended outcome

- Read-only brokerage imports through an approved provider.
- Multi-account and household portfolio views.
- Tax-lot and transaction-history reconciliation.
- Connection health, refresh timestamps, disconnect, and deletion controls.

## Entry gates

- Complete provider sandbox and commercial-license reviews.
- Pass cross-user authorization and encrypted-token handling tests.
- Define incident, retention, provider outage, and user deletion procedures.
- Keep every order-placement capability disabled.
